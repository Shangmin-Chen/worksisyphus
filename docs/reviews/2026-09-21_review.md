## Architecture & Boundary Health (Hexagonal Layout)

The codebase has been restructured into strict architectural compartments:

```text
src/worksisyphus/
├── core/
│   ├── domain/               # Pure models, trimming rules, and quality gates (Zero I/O)
│   ├── rendering/            # Jake's LaTeX resume template renderer (verbatim TeX values)
│   └── use_cases/            # Application lifecycle, tailor pipeline, evaluation
├── ports/                    # Formal Protocol boundaries (CompilerPort, AtsExtractorPort, etc.)
├── adapters/
│   ├── inbound/cli/          # CLI command parsing and routing
│   └── outbound/             # Concrete implementations (LaTeX pdflatex, PDF ATS, SQLite, Git)
├── roles/                    # Upstream and curated HackerRank role rubrics
└── *.py                      # Backward-compatibility facades forwarding to core/adapters
```

### Boundary Compliance:
1. **Core Domain Isolation**:
   - `core/domain/models.py`, `rules.py`, `gates.py`, and `plan.py` have zero external dependencies.
   - Core domain functions operate on plain in-memory strings and dataclasses.
2. **Ports & Dependency Inversion**:
   - Defined strict `@runtime_checkable` protocols: `CompilerPort`, `AtsExtractorPort`, `StoragePort`, `GitGuardPort`, `RoleRubricPort`.
   - Use cases accept injected ports, making mock testing trivial without invasive module monkeypatching.
3. **Deduplicated Facades**:
   - Eliminated over 4,000 lines of duplicate code in root files (`src/worksisyphus/*.py`).
   - Root modules act as clean, typed facades re-exporting core models, use cases, and adapters.

## Over-Engineering & Backlog Triage

Historical backlog accumulated 25 open issues and 16 open PRs. Following architectural triage, over-engineered subsystems were decommissioned:

### Decommissioned Subsystems:
1. **Turso Cloud Sync & Git Guard Freshness**:
   - Closed 10 issues (#46, #49, #50, #67, #68, #73, #78, #79, #82, #85) and 4 PRs (#52, #55, #56, #61).
   - *Rationale*: A single-user resume compiler does not need distributed LibSQL replication, two-phase commit between disk and cloud, or network freshness git guards. Local `applications/` folders already permanently freeze delivered resumes.
2. **Mock HackerRank "Hiring Agent"**:
   - Closed 2 issues (#47, #69) and 2 PRs (#54, #58).
   - *Rationale*: Keyword-based stub returning hardcoded 97.5 scores provided zero hiring signal and caused downstream scoring corruption.
3. **Knapsack Line-Budget Optimizer**:
   - Closed 3 issues (#70, #71, #80) and 1 PR (#60).
   - *Rationale*: Heuristic LaTeX line calculation in Python without pdflatex is superseded by real agent judgment (`--plan`) and the mechanical trim loop.
