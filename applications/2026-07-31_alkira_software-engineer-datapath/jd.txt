THE MISSION

When a company connects its data centers, clouds, and offices on Alkira, our team is what makes it happen. The customer tells us what they want — connect these networks, across these clouds, with these policies — and we turn that into a real, working network in minutes instead of weeks, automatically.

We're the Playbooks / Orchestration team, and we build that automation. Using a mix of Ansible, Python, and Go, we set up the networking stack on our Cloud Exchange Points (CXPs) and run the workflows that keep it healthy — including tricky operations like safely restarting a node. We bring up new virtual network functions (VNFs), build the tooling and CLI used to inspect and configure each node, and work closely with the Routing, Data Path, and Backend teams. Our team spans the US and India, and above all we make sure every customer network comes up correctly and reliably, across every cloud.

WHAT YOU'LL WORK ON

- Automate the cloud. Write the Ansible playbooks that provision infrastructure and stand up network services across AWS, Azure, and GCP — VPCs/VNets, subnets, tunnels, NAT, routing, and security policy.
- Build the engines. Develop the Go task engines that push this configuration onto the CXP nodes at scale — running provisioning and teardown against live state, and rebuilding a node's entire configuration after a controlled restart.
- Bring up new capabilities. Integrate new VNFs as we light up new services and capabilities.
- Own the tooling. Build the Python tooling and CLI engineers use to inspect, configure, and debug the networking stack on the nodes.
- Model the work. Extend the configuration and task models that translate a single provisioning request into the exact commands applied on the nodes.
- Keep it fast and correct. Help connectivity stay correct, fast, and reliable across clouds and at scale.
- Solve real problems. Chase tricky production provisioning issues to their root cause and drive the fix — and collaborate with Routing, Data Path, and Backend on how configuration flows end to end.
